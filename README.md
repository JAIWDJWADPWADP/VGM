# Велгазмаркет — статический сайт

HTML, CSS и обычный JavaScript. Сборка, npm, база данных и серверная часть не нужны.

## Запуск

Из папки сайта:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Проверяйте сайт через локальный HTTP-сервер. Для публикации загрузите `index.html`, `privacy.html`, `style.css`, `script.js`, `theme.js` и папку `assets` на статический хостинг с HTTPS.

## Отправка заявок на почту

Используется Formspree: браузер отправляет форму напрямую по HTTPS, а сервис доставляет письмо на подтверждённый адрес получателя. Зависимостей и секретных ключей в сайте нет.

1. Создайте форму в Formspree и подтвердите адрес электронной почты, на который должны приходить заявки.
2. Скопируйте публичный endpoint формы вида `https://formspree.io/f/xxxxxxxx`.
3. В начале `script.js` замените пустую строку:

   ```js
   const FORMSPREE_ENDPOINT = 'https://formspree.io/f/xxxxxxxx';
   ```

   Используйте фактический ID своей формы. Не вставляйте секретные API-ключи в клиентский JavaScript. Endpoint не нужно добавлять в HTML.
4. В настройках Formspree при необходимости ограничьте отправку своим доменом и включите защиту от спама. Если хостинг использует Content Security Policy, разрешите `https://formspree.io` в `connect-src`, сохранив остальные необходимые источники.
5. После публикации отправьте одну собственную тестовую заявку и проверьте письмо в подтверждённом ящике, включая папку «Спам».

**Текущая поставка:** endpoint не задан, поскольку его не было в исходном архиве. При попытке отправки сайт честно сообщает о недоступности формы и предлагает позвонить. Успех не имитируется. Реальная доставка требует выполнения шагов выше.

Имя, телефон, email и согласие обязательны; комментарий необязателен. Есть клиентская валидация, скрытое honeypot-поле `_gotcha`, блокировка повторной отправки, состояния `idle`, `loading`, `success`, `error` и доступные сообщения `aria-live`. Тайм-аут — 15 секунд. При ошибке данные сохраняются; после подтверждённого ответа сервиса поля очищаются. Без JavaScript отправка отключена, доступен телефон.

Серверная проверка и ограничения сервиса Formspree дополняют клиентские проверки. Срок хранения и получателя настройте в своём аккаунте. `privacy.html` описывает передачу данных через Formspree.

## Оформление и поведение

- Светлая палитра — CSS-переменные в `:root`, тёмная — в `[data-theme="dark"]`.
- `theme.js` выполняется до загрузки стилей: выбирает сохранённую тему либо настройку устройства, обновляет подпись кнопки и сохраняет ручной выбор. При недоступном localStorage переключатель продолжает работать.
- IntersectionObserver показывает блоки с каскадом карточек. Без него и при `prefers-reduced-motion: reduce` контент остаётся видимым.
- «Подробнее» раскрывает описание техники поверх следующего ряда без сдвига страницы. Повторное нажатие или Escape закрывает описание; `aria-controls`, `aria-expanded` и `inert` согласованы.
- На мобильных экранах работает меню; фокус, загрузка и ошибки имеют явные визуальные состояния.

## Файлы

- `index.html` — контент, контакты и форма.
- `style.css` — адаптивная вёрстка, палитры, состояния и анимации.
- `script.js` — меню, навигация, карточки, появление блоков, счётчики, валидация и отправка формы.
- `theme.js` — выбор темы на обеих страницах.
- `privacy.html` — политика конфиденциальности.
- `assets/` — локальные фотографии и favicon.
- `PHOTO-SOURCES.md` — сведения об исходных фотографиях.
- `CHANGES.md` — изменения и результаты проверок.

Название файла фотографии может содержать марку техники для сохранения совместимости с исходными ресурсами. Видимые подписи и alt используют типы техники.
